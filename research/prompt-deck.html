6 references, dissected 5 copy-paste prompts incl. the admin screen

分解What each reference is actually doing

kasoudesign のリンクは掲載ページだったので、紹介されている実サイトまで辿って見ています。左の色帯は各サイトの実際の配色です。

日東紅茶 100 PICNIC100th.nittoh-tea.com

昭和ポスターの熱量。クリーム地に一色の赤、上端に流れるマーキー、左に固定されたサイドバー、角丸ゼロ・溝ゼロで突き合わせたカード群。カードごとに地色が違う。

盗む記事ごとの巨大な通し番号（06・05・04）と、ヘッダーの 06/100 という進捗表示。「積み上がっていく作品集」であって、流れていくフィードではない。前回の継続の話に、そのまま効きます。

BARFOUT!barfout.jp

紙の雑誌をそのままWebに置いた設計。極太のディドネ系セリフの題字が画面の主役で、その上下はほぼ余白。ナビは小さく大きく字間を空けた欧文のみ。

盗む題字を雑誌の題字として扱う覚悟。そして写真パネルをずらして重ねるコラージュ組み。写真の多いブログに一番効く構図です。

mud Inc.mud.co.jp

ほぼ無彩色。画面の内側に一本の細い枠を引いて、額装したように見せている。等高線のような線がゆっくり動き続け、それだけが個性を担っている。

盗む内側の細枠（額装）は実装数行で品が出る、費用対効果が異常に高い手。それと生成モチーフを一つだけ持つという考え方。これは投稿数に応じて育つ絵にできます。

umi.designumi.design

画面いっぱいのフラットイラストが一枚。海沿いの遊歩道、白いワンピースの人、灯台、自転車。ロゴが波の形そのものとしてイラストに溶け込んでいる。全面に粒子のテクスチャ。

盗む六つの中で一番あたたかい。イラスト一枚を主役にする勇気。しかもこれは七十二候で絵を差し替える仕掛けにできて、前回話した「書くことがない日」の対策と直結します。

UGOKKOugokko.jp

こども向け。極太の丸ゴシックが画面外まではみ出し、写真は切り抜き、ぬいぐるみのキャラクターが散らばる。右端に縦書きのタブが貼り付いている。

盗む右端の縦書きタブは日本のUIらしい解で、「今日の一枚を書く」の常時ボタンに最適。あとはキャラクター。継続の仕掛けを持たせるなら、Duolingoのフクロウに当たる役が要ります。

Meliusmelius.com

唯一ブログではなくSaaSのLP。ドット方眼の地、上部に告知バー＋黒の固定ナビ。中央の消失点に向かって画像が奥へ扇状に並ぶ。

盗む遠近で奥に流れる画像の扇。これを過去記事のアーカイブ表示にすると、写真が多いほど気持ちよくなる。あとディドネ系セリフ＋無個性サンセリフの組み合わせ。

参考の傾向について、一つ気づいたこと

六つとも太くて・大きくて・色が強い方向です。前回の企画書で出した三案のうち、あなたが今回集めてきたものに一番近いのは C（縦書きzine）で、一番遠いのが A（静謐）でした。

これは有力な手がかりなので、下のプロンプトはその傾向に寄せてあります。ただし読むのは彼女なので、最終的な好みは本人に確認してください。あなたの好みと彼女の好みがずれている可能性は普通にあります。

使い方How to run these

01

そのまま貼る

プロンプトは全部入りで書いてあります。要約したり削ったりせず、丸ごと貼ってください。日本語組版の制約が効かなくなります。

02

1〜4を全部回す

一本ずつ別々に投げて、四つ出揃ってから並べて選ぶ。一本目で決めないこと。比較しないと good か普通かが分かりません。

03

05は最後に

05は管理画面用です。1〜4のどれを選んだかが決まってから、冒頭の一行だけ差し替えて投げてください。

04

彼女に見せる

出てきた画面を並べて本人に選んでもらう。説明はせず、黙って見せるのが一番正確です。

プロンプトFive prompts, copy-paste ready

01
番号日記The Numbered Journal
系譜 — 日東紅茶 100 PICNIC 主軸 ＋ mud の番号付け
記事に通し番号を振って、積み上がる作品集として見せる案。流れて消えるフィードにしない。継続の仕掛けをデザインそのものに埋め込む、一番ふさわしい方向です。
Prompt 01
日本語の個人ブログをデザインしてください。書き手は日本人の女性で、日々のこと・ごはん・散歩など、テーマを絞らず毎日書きます。文章と写真が中心です。

【画面】次の2枚を作ってください。
1. 記事一覧（トップページ）
2. 記事詳細ページ

【方向性】
1970年代の日本のプロダクトポスターの熱量を、個人の日記に適用する。堂々として、グラフィックで、あたたかい。企業的でもミニマルでもない。

【この案の核 — 必ず入れること】
記事ごとに「通し番号」を振る。047番の記事なら、カード内に 180px 級の巨大な数字「047」をアクセント色で置く。これは流れていくフィードではなく、積み上がっていく作品集である、という思想を視覚化するもの。
ヘッダーには「047 / 100」という進捗表示を置く（100本を目標にしている）。

【配色】
- 地色 #EDE7DA（温かみのある紙色）
- 文字 #1A1613
- アクセント #D6301C（強い赤 — 数字・タグ・罫線に使う）
- 補助 #2E5E4E（深緑）
- カードの地色は次を順番に使い回す: #7FB2C4 / #F2C230 / #E8825A

【書体】
Zen Kaku Gothic New。見出しと数字は 900、本文は 400。
欧文の小ラベルは大文字・字間 0.18em。

【レイアウト】
- 左に固定サイドバー（240px）: ロゴ、ナビ（記事 / タグ / About）、進捗表示。スクロールしても動かない。
- 右は全幅のカードグリッド 3列。溝（gap）なし、角丸なし。印刷物のようにカード同士を突き合わせる。
- カード構成: 上部に色帯（帯の中にキャプション）→ 写真 → 下半分は生成りの地に、カテゴリのピル＋日付、見出し、右下に巨大な通し番号。
- 画面最上部に赤地のマーキー（横に流れる帯）。最新記事のタイトルを流す。

【日本語組版 — 必須】
- 本文 line-height 1.9、letter-spacing 0.05em、一行あたり日本語35文字まで
- font-style: italic は絶対に使わない（日本語に斜体は存在せず、ブラウザが不格好に合成する）。強調は太さか「」で行う
- 見出しは 1.4 まで詰めてよいが、本文は必ず空ける

【使う文言 — ロレムイプサムは使わず、これをそのまま使うこと】
- サイト名: うめの日記
- 記事タイトル: 「六月、雨の匂いについて」「週末に作ったスープ」「新しい器を買った日」「駅裏の古本屋」
- カテゴリ: #日々 #ごはん #さんぽ
- 本文: 朝はいつも同じ道を歩く。角のパン屋が開くのは七時ちょうどで、それより早く着いてしまった日は、川沿いのベンチに座っている。

【やらないこと】
大きな角丸、ドロップシャドウ、グラデーションのヒーロー、絵文字をアイコン代わりに使うこと、全部中央揃え。
02
月刊うめThe Masthead
系譜 — BARFOUT! 主軸 ＋ Melius の遠近ギャラリー
ブログを月刊誌として扱う案。記事は「号」にまとまり、題字が画面の主役になる。写真が多いほど強くなる構成で、毎日ではなく月のリズムで続けたい人に向きます。
Prompt 02
日本語の個人ブログをデザインしてください。書き手は日本人の女性で、文章と写真を投稿します。これを「個人が出している月刊誌」として設計してください。

【画面】次の2枚を作ってください。
1. トップページ（題字＋最新号＋バックナンバー）
2. 記事ページ（雑誌の見開きのような組み）

【方向性】
紙の雑誌をそのままWebに置く。上品で、静かで、余白が主役。カルチャー誌の佇まい。

【この案の核 — 必ず入れること】
1. 題字を「雑誌の題字」として扱う。画面幅の 60〜70% を占める巨大なディドネ系（高コントラストの明朝／セリフ）で組み、その上下は思い切って空ける。題字がヒーローそのもの。
2. 記事を「号」にまとめる。2026年9月号、8月号…とバックナンバーが並ぶ。
3. 写真パネルを「ずらして重ねる」。グリッドに揃えず、数ピクセル〜数十ピクセル単位で意図的にオフセットさせ、紙を並べたコラージュのように見せる。
4. バックナンバーの一覧は、中央の消失点に向かって奥へ扇状に並ぶ遠近のギャラリーにする（CSS transform の perspective を使う）。

【配色】
- 地色 #FBFBF9
- 文字 #111111
- アクセント #D8202F（赤 — 「最新号」バッジと細い罫だけに使う。それ以外に使わない）
- 補助 #6E6B4A（カーキ）
- 罫線 #C9C6BD

【書体】
- 題字・大見出し: Shippori Mincho 600（高コントラストで雑誌的）
- 本文・ナビ: Zen Kaku Gothic New 400 / 500
- ナビは欧文のみ、大文字、字間 0.2em、10〜12px の小さいサイズ

【レイアウト】
- ナビは上端に小さく水平に。ロゴは置かない（題字が下にあるため）
- 題字の周囲は上下に最低 15vh の余白
- 記事ページは1段組み、本文幅は日本語35文字。写真は本文幅を超えて左右にはみ出してよい（フルブリード）
- 写真の上に白文字で小さなキャプションを重ねる

【日本語組版 — 必須】
- 本文 line-height 1.95、letter-spacing 0.05em、一行あたり日本語35文字まで
- font-style: italic は絶対に使わない。強調は太さか「」で
- 明朝は見出しに、ゴシックは本文に、という役割分担を守る

【使う文言 — ロレムイプサムは使わず、これをそのまま使うこと】
- 題字: UME（サブに「うめ」）
- 号: 2026年9月号 / 特集「あたらしい器」
- 記事タイトル: 「六月、雨の匂いについて」「週末に作ったスープ」「駅裏の古本屋」
- 本文: 朝はいつも同じ道を歩く。角のパン屋が開くのは七時ちょうどで、それより早く着いてしまった日は、川沿いのベンチに座って、水面が明るくなっていくのを眺めている。

【やらないこと】
カードUI、角丸、影、グラデーション、サイドバー、絵文字。雑誌に無いものは置かない。
03
七十二候The Seasonal Scene
系譜 — umi.design 主軸 ＋ UGOKKO の縦タブとキャラクター
一枚のイラストが主役で、それが五日ごとに変わる案。七十二候（一年を72に割った古い暦）に合わせて絵と季語が入れ替わるので、「書くことがない日」の入口が自動で毎回用意されます。六案で一番あたたかい方向。
Prompt 03
日本語の個人ブログをデザインしてください。書き手は日本人の女性で、日々のことを文章と写真で綴ります。やわらかく、季節を感じる設計にしてください。

【画面】次の2枚を作ってください。
1. トップページ（季節のイラスト＋記事一覧）
2. 記事ページ

【この案の核 — 必ず入れること】
1. トップの最上部を、画面いっぱいの「フラットベクターのイラスト一枚」にする。写真ではなくイラスト。奥行きのある風景（例: 秋の川べり、木、歩いている人、自転車）を、少ない色数の平面的な塗りで描く。全面に細かい粒子（グレイン）のテクスチャを薄く重ねる。
2. このイラストは「七十二候」に連動して変わる、という設定にする。画面のどこかに現在の候を小さく明朝で表示する。例: 「白露 末候 ─ 玄鳥去（つばめさる）」。日付とセットで、イラストの隅に静かに置く。
3. ロゴをイラストの一部として描く。独立したロゴを置くのではなく、風景の要素（水面の波、雲、木の枝など）がそのまま文字の形になっているようにする。
4. 画面右端に、縦書きの細いタブを貼り付ける。「今日の一枚を書く」というボタンで、スクロールしても常に right:0 に固定される。日本のサイトでよく見る縦長のピル型タブの形にすること。

【配色】
- 空・水 #4A9FD8 → #1C7BB8 のなだらかなグラデーション（イラスト内のみ。UIには使わない）
- 地色 #F2E8D8
- 差し色 #E8845C（オレンジ）と #D8C86A（くすんだ黄）
- 文字 #2A3A42

【書体】
- 見出し・季語: Shippori Mincho 600
- 本文・UI: Zen Kaku Gothic New 400 / 500
- 欧文の小ラベルは字間 0.25em と極端に空ける（参考にした umi.design の特徴）

【レイアウト】
- イラストは最低 70vh。その下から記事一覧が始まる
- 記事一覧は2列。カードは角丸 8px 程度、影は使わず細い罫で囲む
- 各カードに写真、日付、タイトル、2行の抜粋

【日本語組版 — 必須】
- 本文 line-height 1.9、letter-spacing 0.05em、一行あたり日本語35文字まで
- font-style: italic は絶対に使わない。強調は太さか「」で
- 季語や候の名前は明朝で、字間を広めに

【使う文言 — ロレムイプサムは使わず、これをそのまま使うこと】
- サイト名: うめ
- 候の表示: 白露 末候 ─ 玄鳥去（つばめさる） / 2026.09.12
- 記事タイトル: 「六月、雨の匂いについて」「週末に作ったスープ」「新しい器を買った日」
- 本文: 朝はいつも同じ道を歩く。角のパン屋が開くのは七時ちょうどで、それより早く着いてしまった日は、川沿いのベンチに座っている。

【やらないこと】
写真のヒーロー画像、濃い影、紫〜青のグラデーション、絵文字、ステレオタイプな和風の意匠（市松、麻の葉、鳥居、桜の花びらを散らすなど）。あくまで現代のイラストレーションで季節を出すこと。
04
額装The Quiet Frame
系譜 — mud Inc. 主軸 ＋ BARFOUT! の余白
ほぼ無彩色で、画面の内側に細い枠を一本。個性は投稿数に応じて育つ生成モチーフ一つだけが担います。飽きが来ず、写真の色を邪魔しない。四案で一番長持ちする方向。
Prompt 04
日本語の個人ブログをデザインしてください。書き手は日本人の女性で、文章と写真を投稿します。極度に静かで、写真の色を一切邪魔しない設計にしてください。

【画面】次の2枚を作ってください。
1. トップページ
2. 記事ページ

【方向性】
ほぼ無彩色。色数を絞りきり、余白と罫線と組版だけで品位を出す。装飾は一切しない。

【この案の核 — 必ず入れること】
1. 「額装」— ビューポートの内側 16px の位置に、1px の細い枠線を四辺に引く。中身はこの枠の内側でスクロールする。作品を額に入れたように見せる。これがこの案の署名。
2. 「育つモチーフ」— トップのヒーロー領域に、Canvas で描く生成的な線画を一つだけ置く。等高線のように、ゆっくりとうねる細い線が何本も重なった図形。ゆっくり動き続ける（1周30秒以上かけるくらい遅く）。
   重要: この線の本数は「これまでの投稿数」に比例する、という設定にする。投稿が増えるほど線が密になり、絵が育つ。画面の隅に「148本目」と小さく添える。
3. セクションに番号を振る。「01.」「02.」のように、小さなモノスペースで見出しの左に置く。

【配色】
- 地色 #F2F2F0
- 面 #FFFFFF
- 文字 #121212
- 弱い文字 #9A9A96
- 罫線 #C8C8C4
アクセント色は持たない。色は写真だけが持つ。

【書体】
- 見出し: Zen Kaku Gothic New 700。字間を詰め気味（-0.01em）に、大きく
- 本文: Zen Kaku Gothic New 400
- 数字・ラベル: JetBrains Mono 400、字間 0.15em、大文字
- 欧文見出しの下に、小さく字間を広げたカタカナの副題を添える組み方をする（例: 大きく「Journal」、その下に小さく「ジャーナル」）

【レイアウト】
- 1段組み、本文幅は日本語35文字
- 記事一覧は、カードを使わず「横罫で区切ったリスト」にする。1行に 日付 / タイトル / タグ
- 写真は本文幅いっぱい。角丸なし、影なし
- ホバー時のみ罫線の色が変わる程度の、極小の反応

【日本語組版 — 必須】
- 本文 line-height 2.0、letter-spacing 0.05em、一行あたり日本語35文字まで
- font-style: italic は絶対に使わない。強調は太さか「」で
- 見出しと本文の書体は同じ。太さと大きさだけで階層を作る

【使う文言 — ロレムイプサムは使わず、これをそのまま使うこと】
- サイト名: うめ / ume
- 記事タイトル: 「六月、雨の匂いについて」「週末に作ったスープ」「新しい器を買った日」「駅裏の古本屋」
- 投稿数の表示: 148本目
- 本文: 朝はいつも同じ道を歩く。角のパン屋が開くのは七時ちょうどで、それより早く着いてしまった日は、川沿いのベンチに座って、水面がゆっくり明るくなっていくのをただ眺めている。

【やらないこと】
色のアクセント、カードUI、角丸、影、グラデーション、アイコン、絵文字、太いボタン。引き算だけで作ること。

書く画面The Admin — run this last
系譜 — UGOKKO のキャラクター ＋ 日東紅茶 の進捗表示 ＋ 前回の継続の設計
参考サイト六つは全部「読む側」の画面でした。でも彼女が毎日開くのは書く側で、続くかどうかはここで決まります。前回話した往復記録・巨大な下限の低さ・折れない数え方を、全部この一枚に入れてあります。01〜04のどれかを選んでから、冒頭の一行を差し替えて投げてください。
Prompt 05
ブログの「管理画面（書く側）」をデザインしてください。使う人はたった一人、毎日書く日本人の女性です。読者向けの画面ではありません。

※ 配色と書体は、先に選んだ案「番号日記 / 月刊うめ / 七十二候 / 額装」のうち___に合わせてください。（← ここに選んだ案の名前を書いてから投げること）

【画面】次の2枚を作ってください。
1. ダッシュボード（ログイン直後に見る画面）
2. 執筆画面（エディタ）

【最重要の前提 — デザインの判断はすべてこれに従うこと】
この人は過去に、ブログを何日か書けなかった時に戻って来られず、そのまま辞めた経験がある。だから次の三つを絶対に守る。
1. 「連続日数」を表示しない。ゼロに戻る数字を画面のどこにも置かない。途切れた瞬間に辞める原因になる。
2. 数えるのは「減らないもの」だけ。通算の本数、今月書いた日数、これまでの最高記録。どれも下がらない。
3. 空白の日を「失敗」として描かない。年間カレンダーは GitHub の草のようなマス目にするが、書かなかった日は赤やバツではなく、単に色が薄いだけにすること。

【ダッシュボードに置くもの】
- 画面の主役は、でかい一つのボタン「今日の一枚を書く」。他の何よりも大きく。
- その真下に小さく「写真1枚と一行でも、立派な一本です」と添える。投稿の下限が低いことを毎日伝えるための文言。
- 年間カレンダー（52週 × 7日のマス目）。書いた日は濃く、書いていない日は薄く。数字は出さない。
- 「これまで 148本」「今月 11日」「最高記録 23日連続」の三つ。※最高記録は過去の実績であり、現在の連続日数ではない。壊れない。
- 「往復 96回」— 相手（パートナー）が返事を書いた回数とのペア表示。彼女が書く → 相手が返事を書く、で1往復。これも減らない数字。
- 相手の最新の返事を、ダッシュボードにそのまま抜粋で表示する。これがこの画面で一番うれしい場所なので、目立つ位置に置くこと。
- 今日の書き出しのヒント（七十二候の季語など）を1行。押すとそれが本文に入る。
- 小さなキャラクターを一体置く。ただし煽らない。急かす・責める・カウントダウンする表現は一切させない。「おかえり」と言うだけの存在にする。

【執筆画面に置くもの】
- Notion 風のブロックエディタ。左に「+」でブロックを追加。
- 上部に、状態を示すごく控えめな表示: 下書き / 確認待ち / 予約済み / 公開中
- 「シンプルモード」のトグル。押すとブロックメニューが消えて、文字だけの画面になる。
- 自動保存の表示。「保存しました 14:32」程度の小ささで。
- 画像はドラッグ＆ドロップ。枠を点線で示す。
- 公開ボタンの隣に「あとで読み返す」（＝下書き保存）を同じ重さで置く。公開だけを正解にしない。

【日本語組版 — 必須】
- 本文・エディタ内 line-height 1.9、letter-spacing 0.05em
- font-style: italic は絶対に使わない
- エディタの本文幅は日本語35文字

【使う文言 — ロレムイプサムは使わず、これをそのまま使うこと】
- ボタン: 今日の一枚を書く
- 数値: 148本 / 今月11日 / 最高記録23日 / 往復96回
- 相手の返事の抜粋: 「スープの写真、湯気まで写ってた。あれ何時ごろ？」
- ヒント: 白露 末候 ─ 玄鳥去。つばめが南へ帰るころ。
- 編集中の記事タイトル: 新しい器を買った日

【やらないこと】
連続日数のカウンター、炎のアイコン、「あと◯時間で記録が途切れます」の類、ポイント、バッジ、レベル、ランキング、赤い警告、通知バッジの数字。どれも「書かないと損をする」という気持ちを作る装置で、この人には逆効果になる。使う感情は「誰かが待っている」だけにすること。
